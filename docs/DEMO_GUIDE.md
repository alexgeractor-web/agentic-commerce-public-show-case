# Public demo guide / Руководство по демо

[Open simulated sandbox](https://agentic-commerce-public-sandbox.netlify.app/)

The linked demonstration is a **synthetic scenario**, not a production shop or live AI checkout.

## Suggested walkthrough

1. Review the four synthetic products, demo stock and session metrics.
2. Select an example product and create a **simulated** order.
3. Inspect changes to inventory, the session order list and the sample event log.
4. Reset the visitor's demo session.

## Important limitations

- No customer funds are transferred; there are no real payment confirmations or fiscal receipts.
- The "AI channel" in the publicly deployed demo is a scripted label, not evidence of a real independent AI buyer.
- Product amounts and revenues are fictional; figures do **not** represent real customer traction.
- Cookie/session demo state is **not** a transactional source of truth; cross-device and concurrent writes are not supported as a merchant workflow.
- Reliability, uptime, availability and protections depend on the deployed revision and hosting provider, and are **not** certified by this presentation.
- Never submit real customer information, card details, secrets or production tokens.

**По-русски:** Это тестовая симуляция для ознакомления. Она не подключена к реальному интернет-магазину, не обрабатывает настоящие покупки и не подтверждает готовность системы к работе с реальными платежами.
