# Security and responsible disclosure

This repository is a public **informational showcase**, separate from proprietary implementation. The linked public demo is a synthetic, non-production sandbox.

## Report privately

To report a possible vulnerability, write to **agenticcommerce975@gmail.com** with the subject "Agentic Commerce — security report".

Initially share a high-level description only. Do **not** publicly post exploitable steps, credentials, personal data, card numbers or proprietary customer information in GitHub Issues. Do not carry out unauthorized intrusive testing against hosted or third-party systems.

No security response-time SLA or bug bounty is represented by this repository.
